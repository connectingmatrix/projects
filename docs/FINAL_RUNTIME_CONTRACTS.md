# @connectingmatrix/projects final runtime contracts

This file is generated by the final process-monitor / project / nodes / workflow-AI / Giga-agents hardening pass.

## Ownership

- Agent Project CRUD
- source tree and temporary mounted sessions
- build/run/deploy/deployment logs
- project heartbeat and errored-state updates
- project software-builder assistant
- connected DB registration/query execution
- ClickHouse-style debug events
- Supabase source archive handoff through @connectingmatrix/file
